# Utkal Agro Industries website

    npm install
    npm run dev      # development
    npm run build    # production build in /dist

1. Add photos to `public/images/` (see README.txt there).
2. Edit your details in `src/data/company.js`.
3. Edit text lists in `src/data/` (products, process steps, FAQs, gallery, nav links).
4. Colors and fonts live in `src/styles/variables.css`.
